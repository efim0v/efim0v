### Contributions

Fixes I sent to projects I use, merged by their maintainers.

- [Rectangle](https://github.com/rxhanson/Rectangle): [#1911](https://github.com/rxhanson/Rectangle/pull/1911) On MacBooks with a notch, the top gap can now be set to zero
- [SwiftFormat](https://github.com/nicklockwood/SwiftFormat): [#2761](https://github.com/nicklockwood/SwiftFormat/pull/2761) Build folders are now skipped by default
- [git-town](https://github.com/git-town/git-town): [#6298](https://github.com/git-town/git-town/pull/6298) A branch open in another worktree can now be set as the parent branch
- [drift](https://github.com/simolus3/drift): [#3875](https://github.com/simolus3/drift/pull/3875) Columns named “text” or “map” no longer break the code; [#3876](https://github.com/simolus3/drift/pull/3876) Docs on keeping data safe when an update is interrupted
- [obsidian-omnisearch](https://github.com/scambier/obsidian-omnisearch): [#585](https://github.com/scambier/obsidian-omnisearch/pull/585) Search now finds files with uppercase extensions, like “Scan.PDF”, and BMP images
- [image](https://github.com/brendan-duncan/image): [#812](https://github.com/brendan-duncan/image/pull/812) Some PNGs under 5 pixels wide no longer crash the decoder
- [archive](https://github.com/brendan-duncan/archive): [#423](https://github.com/brendan-duncan/archive/pull/423) A partly read zip file no longer opens empty
